Dos funciones para imprevistos en carretera

El NETSU-T02 combina un arrancador portátil para asistir el encendido de un vehículo con batería descargada y un compresor para inflar llantas. Es una opción compacta para llevar en el carro y estar mejor preparado durante viajes y recorridos diarios.

¿Para qué sirve?

  • Arranque de emergencia: permite asistir el arranque de vehículos compatibles mediante pinzas, sujeto a los límites técnicos del modelo.
  • Inflado de llantas: compresor portátil para revisar e inflar neumáticos según las instrucciones del fabricante.
  • Control digital: pantalla para consultar los parámetros de inflado anunciados para este equipo.
  • Portabilidad: equipo pensado para guardar y transportar en el vehículo.
